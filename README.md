# 💌 Our Little Story ♡ — เว็บไซต์เซอร์ไพรส์สโน จากบลู

เว็บไซต์สมุดบันทึกความทรงจำน่ารักอบอุ่น (Cute Romantic Scrapbook) สไตล์รูปโพลารอยด์ เทปกระดาษ และจดหมายเปิดผนึก เพื่อเล่าเรื่องราวความผูกพันและนำไปสู่เซอร์ไพรส์เค้กในลิ้นชักหน้ารถจริง ๆ 🎂🤍

---

## ✨ ไฮไลต์และการออกแบบ

1. **Opening Screen 💌:** หน้าปกสมุดบันทึกและซองจดหมายผูกริบบิ้น เมื่อแตะจะเปิดซองอย่างนุ่มนวลและเลื่อนลงไปอ่านเนื้อหา
2. **Our Little Memories 📸:** การ์ดโพลารอยด์ 6 ภาพ ติดเทปกระดาษสีพาสเทล พร้อมหัวข้อ แคปชัน และวันที่ สามารถรองรับทั้งรูปแนวตั้งและแนวนอนโดยไม่ผิดสัดส่วน
3. **Little Things I Love About You 🌷:** การ์ดโน้ตบอกความรู้สึก 4 ใบ สไตล์กระดาษโน้ตน่ารัก ขยับเบา ๆ เมื่อสัมผัส
4. **A Little Note Before the End ♡:** หน้าคั่นบรรยากาศสงบ ก่อนส่งต่อไปยังจดหมายฉบับสุดท้าย (ไม่มีการบอกใบ้เรื่องเค้กก่อนเวลา)
5. **The Final Letter 💌:** จดหมายเปิดผนึกฉบับสำคัญ พร้อมเอฟเฟกต์คอนเฟตติหัวใจละมุนตา บรรทัดสำคัญ: **“สโนคะ หันไปลองเปิดลิ้นชักด้านหน้าดูหน่อยค่ะ 🎂🤍”** อยู่ช่วงท้ายอย่างเป็นธรรมชาติ
6. **Final Screen 🎂:** ปิดท้ายอย่างอบอุ่นและเรียบง่าย “Our story is still being written... ♡” โดยไม่เปิดเผยรูปเค้กจริงบนเว็บ
7. **Romantic Music Player 🎵:** เครื่องเล่นเพลงแผ่นเสียงมุมจอที่บลูขอไว้:
   - ปิด/เปิดเพลงได้ตามต้องการ (ไม่เปิดอัตโนมัติ)
   - ปรับระดับเสียงดัง-เบาได้
   - แสดงชื่อเพลง ศิลปิน และปกแผ่นเสียงหมุนช้า ๆ
   - มีเพลงอะคูสติกโรแมนติกพร้อมเล่นทันที หรือใส่เพลงโปรดเป็นไฟล์ `.mp3` ได้ง่าย ๆ
8. **โหมดลองจัดรูปภาพ (Photo Preview Mode):** ปุ่มลับมุมซ้ายล่าง เพื่อให้บลูสามารถจิ้มเลือกรูปจากเครื่องลองพรีวิวบนหน้าเว็บได้ทันทีก่อน Deploy จริง

## 📸 วิธีใส่รูปภาพความทรงจำจริงของเรา

1. เตรียมรูปถ่ายของบลูและสโน 6 รูป
2. นำไฟล์รูปภาพมาวางในโฟลเดอร์ `public/images/`
3. ตั้งชื่อไฟล์ให้ตรงตามนี้:
   - `photo-1.jpg` (Memory 1 — The Beginning)
   - `photo-2.jpg` (Memory 2 — A Little Moment)
   - `photo-3.jpg` (Memory 3 — Your Smile)
   - `photo-4.jpg` (Memory 4 — Our Memories)
   - `photo-5.jpg` (Memory 5 — Little Things)
   - `photo-6.jpg` (Memory 6 — More to Come)

*(หากยังไม่ได้ใส่รูปจริง ระบบจะแสดงกรอบภาพวาด Doodle Scrapbook พร้อมไอคอนและข้อความน่ารัก ๆ ให้อัตโนมัติ โดยที่เว็บไม่พังและยังดูสมบูรณ์สวยงาม 100%)*

## ✍️ วิธีแก้ไขข้อความ ชื่อ และเนื้อหาจดหมาย

เปิดไฟล์ `src/content.ts` บลูจะพบข้อความภาษาไทยที่มีคำอธิบายชัดเจน สามารถแก้ไขได้ง่าย ๆ:

- **ชื่อ:** แก้ไขตรง `couple.boyfriendName` ('บลู') และ `couple.girlfriendName` ('สโน')
- **ข้อความใต้รูป 6 รูป:** แก้ไขในส่วน `memories` (หัวข้อ, วันที่, แคปชัน)
- **ข้อความในการ์ด 4 ใบ:** แก้ไขในส่วน `reasonsSection.reasons`
- **เนื้อหาจดหมายสุดท้าย:** แก้ไขในส่วน `finalLetter.paragraphs` และประโยคเปิดลิ้นชักรถ `finalLetter.cakeClue`
- **เพลง:** แก้ไขในส่วน `music` (ชื่อเพลง, ศิลปิน, ลิงก์เสียง หรือไฟล์ `/music/song.mp3`)

## 💻 คำสั่งสำหรับรันในเครื่อง (Local Development)

เปิดโปรแกรม Terminal หรือ PowerShell ในโฟลเดอร์โปรเจกต์นี้:

```bash
# 1. ติดตั้ง Dependencies (ทำครั้งแรกครั้งเดียว)
npm install

# 2. เปิดใช้งานเว็บไซต์ในเครื่อง
npm run dev
```

เปิดเบราว์เซอร์ไปที่ `http://localhost:5173` เพื่อดูหน้าตาเว็บได้ทันที

## 🚀 วิธีนำขึ้นอินเทอร์เน็ต (Deploy) ให้สโนเปิดบนมือถือได้ฟรี

มี 2 วิธีที่ง่ายและเร็วที่สุด (แนะนำวิธีที่ 1 ผ่าน Vercel หรือ Netlify):

### วิธีที่ 1: Deploy ผ่าน Vercel (เร็วที่สุดและฟรี ไม่เกิน 2 นาที)
1. สมัครหรือเข้าสู่ระบบที่ [vercel.com](https://vercel.com) (เข้าสู่ระบบด้วย GitHub หรือ Email)
2. ติดตั้ง Vercel CLI ในเครื่องโดยพิมพ์ใน PowerShell:
   ```bash
   npm install -g vercel
   ```
3. พิมพ์คำสั่ง:
   ```bash
   vercel
   ```
4. กด Enter ยอมรับค่าเริ่มต้น รอสักครู่ จะได้ลิงก์เว็บไซต์ เช่น `https://snow-our-story.vercel.app`
5. ส่งลิงก์นี้ให้สโนทาง LINE หรือเปิดผ่าน Safari / Chrome บนมือถือได้เลย!

### วิธีที่ 2: Drag & Drop ผ่าน Netlify Drop (ไม่ต้องใช้คำสั่ง)
1. ในโฟลเดอร์โปรเจกต์ พิมพ์คำสั่ง:
   ```bash
   npm run build
   ```
2. จะเกิดโฟลเดอร์ชื่อ `dist` ขึ้นมาในโปรเจกต์
3. เปิดเว็บ [app.netlify.com/drop](https://app.netlify.com/drop)
4. ลากโฟลเดอร์ `dist` ไปวางในหน้าเว็บ Netlify
5. จะได้ลิงก์เว็บไซต์ทันที สามารถตั้งชื่อโดเมนน่ารัก ๆ ได้ฟรี เช่น `sno-and-blue.netlify.app`
