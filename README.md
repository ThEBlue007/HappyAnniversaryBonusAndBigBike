# 💌 Our Little Story ♡ — เว็บไซต์เซอร์ไพรส์สโน จากบลู

เว็บไซต์สมุดบันทึกความทรงจำแบบภาพยนตร์เล่าเรื่องฉากต่อฉาก (Interactive Storytelling) สไตล์รูปโพลารอยด์ เทปกระดาษ และจดหมายเปิดผนึก เพื่อเล่าเรื่องราวความผูกพันและนำไปสู่เซอร์ไพรส์เค้กในลิ้นชักหน้ารถจริง ๆ 🎂🤍

---

## ✨ ลำดับเรื่องราว 10 ฉาก (Storyline Flow)

1. **Scene 01 — Opening:** ซองจดหมายหน้าปกสมุดบันทึก → ปุ่ม *“เริ่มเรื่องราวของเรากัน ♡”*
2. **Scene 02 — Memory 1 (1 รูป):** จุดเริ่มต้นของเรา (`photo-1.jpg`)
3. **Scene 03 — Memory 2 (3 รูป):** ช่วงเวลาดี ๆ ของเรา (`photo-2-1.jpg`, `photo-2-2.jpg`, `photo-2-3.jpg`) ซ้อนเหลื่อมกัน 3 ใบ แตะรูปไหนเพื่อสลับขึ้นมาข้างหน้าได้
4. **Scene 04 — Memory 3 (3 รูป):** รอยยิ้มของสโน (`photo-3-1.jpg`, `photo-3-2.jpg`, `photo-3-3.jpg`) ซ้อนเหลื่อมกัน 3 ใบ แตะรูปไหนเพื่อสลับขึ้นมาข้างหน้าได้
5. **Scene 05 — Memory 4 (1 รูป):** เรื่องราวที่เราชอบ / ดูหนังด้วยกัน (`photo-4.jpg`)
6. **Scene 06 — Little Question (คำถามเขียนตอบ):** สโนพิมพ์ตอบความรู้สึกในใจ พร้อมบันทึกลงเครื่องอัตโนมัติ (บลูแอบเปิดดูคำตอบได้)
7. **Scene 07 — A Little Note Before the End:** หน้าคั่นซึ้ง ๆ ก่อนเข้าสู่จดหมาย
8. **Scene 08 — The Final Letter:** ซองจดหมายเปิดผนึกพร้อมกระดาษจดหมาย 2 หน้า
9. **Scene 09 — Final Reveal (เซอร์ไพรส์ลิ้นชักหน้ารถ 🎂🤍):** คำใบ้สำคัญ: **“สโนคะ หันไปลองเปิดลิ้นชักด้านหน้าดูหน่อยค่ะ 🎂🤍”**
10. **Scene 10 — Final Screen:** ปิดท้ายอย่างอบอุ่น *“Our story is still being written... ♡”*

## 📸 รายชื่อไฟล์รูปภาพความทรงจำ (รวม 8 รูป)

นำไฟล์รูปภาพมาวางไว้ในโฟลเดอร์ `public/images/` ตามชื่อด้านล่างนี้ได้เลยครับ:

- **ฉากที่ 1 (1 รูป):** `public/images/photo-1.jpg`
- **ฉากที่ 2 (3 รูป):** 
  - `public/images/photo-2-1.jpg`
  - `public/images/photo-2-2.jpg`
  - `public/images/photo-2-3.jpg`
- **ฉากที่ 3 (3 รูป):** 
  - `public/images/photo-3-1.jpg`
  - `public/images/photo-3-2.jpg`
  - `public/images/photo-3-3.jpg`
- **ฉากที่ 4 (1 รูป):** `public/images/photo-4.jpg`

*(หากยังใส่รูปไม่ครบ ใบที่ยังไม่มีไฟล์จะแสดงเป็นการ์ดภาพวาดน่ารัก ๆ สไตล์ Scrapbook พร้อมใช้งานทันทีโดยที่เว็บไม่พัง)*

## ✍️ วิธีแก้ไขข้อความ ชื่อ และคำถาม

เปิดไฟล์ `src/content.ts` บลูจะพบข้อความภาษาไทยที่มีคำอธิบายชัดเจน สามารถแก้ไขได้ง่าย ๆ ในไฟล์เดียวครับ

---

## 🔍 เมนูลับสำหรับบลู (Blue's Secret Menu)
ที่มุมจอล่างซ้าย บลูสามารถแตะปุ่ม **“เมนูลับของบลู ♡”** เพื่อ:
1. **📸 ลองจัดรูปภาพ:** ทดลองเลือกไฟล์รูปจากเครื่องเพื่อดูพรีวิวรูปโพลารอยด์ทั้ง 8 ช่องได้ทันที
2. **💌 แอบดูคำตอบของสโน:** เปิดอ่านคำตอบจริงที่สโนพิมพ์ลงในเว็บสด ๆ พร้อมเวลากดส่ง และปุ่มคัดลอกข้อความ

## 💻 คำสั่งสำหรับเปิดใช้งานในเครื่อง

```powershell
npm run dev
```
เปิดเบราว์เซอร์ที่ `http://localhost:5173`

## 🚀 วิธีนำขึ้นอินเทอร์เน็ต (Deploy) ส่งให้สโนเปิดบนมือถือ

```powershell
npm run build
```
